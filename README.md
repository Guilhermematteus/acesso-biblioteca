# 🎮 Acesso à Biblioteca de Jogos (Python)

Projeto prático desenvolvido em **Python** focado em lógica de programação, manipulação de coleções, estruturas de repetição e controlo de fluxo via terminal (CLI).

## 🚀 Conceitos Aplicados
* **Laços de Repetição (`while`):** Validação contínua de credenciais de acesso até que a condição correta seja atingida.
* **Estruturas de Dados (`list`):** Armazenamento e manipulação de uma lista personalizada de jogos.
* **Iteração (`for`):** Varredura sequencial dos elementos da coleção.
* **Biblioteca Nativa (`time`):** Utilização do método `sleep` para simular efeitos visuais de carregamento no terminal.

## ⚙️ Funcionalidades
1. **Controlo de Acesso por Senha:** Sistema de autenticação simples via linha de comando que bloqueia a exibição do conteúdo em caso de utilizador incorreto.
2. **Carregamento Dinâmico:** Exibição progressiva dos títulos dos jogos com intervalos temporizados.
